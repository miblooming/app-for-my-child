# 奇想学园 · 编程小镇 v1.6.0

面向 4～6 岁儿童的离线编程启蒙游戏。场景在上、编程面板在下，角色到达职业工作点后自动工作，每轮程序结束自动回到起点。

## 安装与预览

- Android：安装 `交付文件/奇想编程小镇-v1.6.0.apk`。支持 Android 8.0（API 26）及以上，旧设备需要支持现代 JavaScript 的 Android System WebView。
- 本版沿用原有项目签名，可覆盖安装并保留本机数据。
- 电脑：双击 `启动预览.cmd`，打开 `http://localhost:5178`。首次安装依赖需要网络；后续游戏、图像和配音都不依赖外网。
- 网页入口需要 HTTP 服务，请勿直接双击 `index.html`。

## 第一关怎么玩

1. 首页默认显示单人关卡。选择“第一颗萝卜”，点 3 次“向右”。
2. 点“开始运行”，先高亮“开始”，把米米放回田里的起点。
3. 下一拍执行第一个“向右”，米米会自动采萝卜，再走一格。
4. 按指令向右走 3 格，到仓库自动存入萝卜。
5. 整段程序结束后才判断结果，停在仓库并放好萝卜就完成本关。随后自动回到起点，无需编写返回路线。

若程序结束时没有停在自己的目的地，播报“未到达目的地，任务失败了”，播完后再播报开始、回到起点。经过目的地却又走开不算成功。多轮关卡会继续执行，直到参与的伙伴都完成指定轮数；自由创造持续循环。

没有额外的“动手”指令。孩子只需编排方向、等待、重复、条件和组合动作。

## 编辑程序

- 编程区紧贴场景下方。下方的指令按钮自动换行，不需要横滑查找；已编排的程序轨道可以左右滑动。
- 手指从场景上滑动，也能滚动整个页面。网格占满场景宽度，格子保持正方形，取消放大缩小。普通地图随页面滚动时可保持场景与编程区相邻；超长关卡随页面自然滚动，便于查看整条路线。
- 点下方图标，在程序末尾添加指令。
- **先点垃圾桶进入删除模式，再点轨道中的指令删除。** 正常模式点击不会删除；删除模式会显示减号标记、“清除”按钮和完成勾选按钮。
- 删除模式下点“清除”，一次清空当前角色的全部指令。点勾选退出删除模式。
- 撤销在正常模式和删除模式下均有效，添加、删除、排序、复杂指令修改及一键清空都可以撤销。
- **长按约 0.4 秒，再拖动指令，松手完成排序。** 拖动不会触发删除，靠近轨道两侧可自动滚动。
- 条件和组合动作旁边的“编辑”铅笔用于修改复杂内容；只有开启删除模式后，点击指令主体才会删除。
- 复杂指令窗口内部也有独立的删除模式、清除与撤销按钮，支持长按拖动排序。
- 键盘用户聚焦指令后，可用 Alt + 左右方向键调整顺序，进入删除模式后可按 Enter 删除。
- 每个主程序最多 48 条指令，复杂指令编辑器最多 24 个动作；撤销保留最近 40 次程序修改。

每次添加、删除、排序、调整重复次数、修改复杂指令或撤销后，运行会自动中断，对应角色立即回到自己的起点，执行栈清空。必须再次点“开始运行”或“下一步”，才从开始执行。打开复杂指令编辑器也会先暂停。手持物品、库存与工作统计保留；本次尝试的该角色成功轮数重新计算，已点亮的星星保留。单人预备食材不足时会补足本次挑战所需物资。只选择重复框或切换删除模式不会修改程序。修改共享拿手动作时，引用它的角色都会回到起点，撤销也会恢复动作定义。

## 队列内的重复框

1. 点“重复”，直接在指令队列里生成一个向上开口的粗边框，默认重复 3 次，并自动选中。
2. 选中框时，提示显示“添加到：重复 N 次框内”；接着点方向、等待、条件或组合，指令会进入这个框。
3. 每个普通指令块大小保持原样。框会随内容横向增长，整个程序仍可左右滑动。
4. 框底边显示重复次数，点减号或加号可调整为 1～9 次。
5. 点“回到主队列”、开始标记或框外的加号，再添加的指令放到主队列末尾。点其他重复框可切换目标。
6. 框内指令长按排序；长按底边“重复 N 次”可移动整个框。支持 Alt + 左右键调整同一队列中的顺序。
7. 开启垃圾桶后可点框内指令删除，框角的垃圾桶可删除整个框；撤销会恢复内容及对应选择。清除按钮仍清空当前角色的整个程序。
8. 支持最多 4 层嵌套，每个重复框通过按钮添加最多 24 条指令。执行时高亮实际动作及所属重复框。

普通暂停保留当前位置和执行进度。“回到起点”按钮将全部角色送回各自起点，保留程序、库存和工作成果。

## 步模式与指令高亮

- 点击底部“步模式”，连续运行会暂停，并准备从“开始”重新演示。
- 第一次点“下一步”，只执行“开始”：重置人物坐标，高亮开始标记；此时不执行第一条方向指令。
- 再点一次“下一步”，才执行第一条指令。之后每点一次，各伙伴执行一条移动或等待指令；重复、条件、组合内部也一次只执行一条。
- 自动采集与到站工作附随在对应指令里；一整轮结束后，“开始”作为独立一步回家，然后才执行下一轮第一条指令。
- 连续运行和步模式都高亮当前步骤，暂停后保留。长程序会横向跟随高亮，手动滑动时暂缓跟随，页面不会上下跳动。
- 开启声音时，下一步按钮会等待当前角色的动作语音播完再恢复，防止连续点击截断语音；静音时等待短暂动作动画。
- 点击“连续运行”即可继续自动执行。步模式不会自行推进。

## 网格与统计

统计放在场景上方的独立栏，不遮住地图。网格默认开启，每格对应一步；所选角色的本关起点及推荐路线步数会标出。场景右上角网格按钮可以显示或隐藏网格与路线提示。道路判断关卡会显示可辨认的路障。

浅色格可以走；斜纹格及其中的建筑、菜田、树木、水面不能走；绿框是可进入的工作点。场景和移动使用同一份整格地形数据，工作点位于建筑旁的可走格。人物、路障、起点与步数按格定位，装饰不再覆盖可走格。隐藏网格后仍能从底色辨认通行区域。

## 自动工作与协作

普通地图采用纵向 7×8 网格，新增专用迷宫最长为 7×13。四个角色可以同时执行各自的程序，角色之间可互相穿过；怪物所在格需先由卫士清理，其他角色才能通过。

| 角色 | 起点 | 推荐程序 | 到达后的自动工作 |
| --- | --- | --- | --- |
| 米米 · 小兔采集员 | 萝卜田 (1,2) | 向右 → 向右 → 向右 | 在田里采萝卜，到仓库 (4,2) 存入 |
| 布布 · 小熊厨师 | 仓库 (4,2) | 向下 → 向下 → 向下 | 从仓库取萝卜，到厨房 (4,5) 做汤并放到取餐台 |
| 点点 · 小鸭配送员 | 取餐台 (4,6) | 向左 → 向左 → 向左 | 从取餐台取汤，到朋友的花园 (1,6) 送餐 |
| 闪闪 · 小狐卫士 | 自由创造 (2,4) | 向下 → 向下 | 移动到怪物同一格自动消灭怪物，清理完后去出口 |

坐标从 0 开始；关卡可以另设起点、取货点和目的地，以地图为准。每个角色只自动执行自己职业对应的工作。萝卜、食材或汤不足时，角色在原工作点等待，资源到来后继续，其他角色照常运行。第 17、18 关点点从仓库取米米送来的萝卜，再送去花园；无米米供货不能完成。停留在工作点时不会反复拿取或重复计数。

整轮程序结束后，角色自动回到自己的起点，下一拍继续工作并循环。重复块或组合动作的内部步骤结束时不会提前回家。自动回家只重置位置和指令游标，不清空库存、成果或尚未送达的手持物品。

## 任务与自由创造

首页默认进入单人关卡，提供 20 个单人和 10 个双人关卡。米米、布布、点点各有 6 个单人练习，闪闪有 2 个巡逻练习；双人关卡包含食材接力、热汤接力和卫士护送。

新增关卡重点体验“重复”和“如果”：第 19、21 关的几字长廊分别至少走 24、36 步，嵌套重复只需 9 个指令格；第 20 关的阶梯路用重复“向右、向下”压缩步骤。第 22～24 关有随机初始位置与停留时间的移动路障，单靠背固定方向不能稳定通过；使用重复“如果前方能走就前进，否则等待”，每次行动重新观察。第 27～29 关由闪闪先清怪，伙伴才能通过；第 30 关要等布布做汤，再判断移动路障送餐。

这些关卡显示每人指令格预算及本关练习要求。重复框本身、框内动作、条件及两边分支均计入格数；运行前检查预算和所需指令，完成时还会检查是否实际执行了练习内容。可以先编写再修改超出的部分。移动路障按负责观察角色的行动节拍更新，暂停、该角色配音期间会等待；路障不会移动到人物正在占据的格子。直接撞向当时关闭的路障会使本次尝试失败。

顶部“关卡”是一级菜单，位于书本图标左边，可随时返回选择单人或双人关卡。编程区只显示本关参加人物的标签：单人 1 个，双人 2 个。每次进入或重新选择关卡，全部人物的指令队列清空，起点、路障和物资重新准备；“继续”保留当前场景及程序，关闭应用后也可从当前存档继续。

顶部书本菜单提供“小镇冒险”“自由创造”“玩法帮助”和“我的星星”。自由创造开放全部 4 个角色和指令，有独立程序草稿。场景旗帜按钮可查看本关任务、条件说明与完整示例。

当前关卡在目录中以高亮边框及“当前关卡”标记显示。场景标题旁的喇叭按钮、关卡说明窗口里的“重新播放关卡说明”按钮都可从头重播本关配音；重播时会先暂停运行。若已静音，请先点顶部声音按钮开启声音。

## 如果条件

条件按人物执行到这一条时的位置与物品实时判断，编辑窗口显示解释和“现在成立 / 现在不成立”，不会把编辑时的结果固定下来。

| 类别 | 条件 |
| --- | --- |
| 道路 | 右边能走、下方能走、左边能走、上方能走；检查相邻一格的路障和地图边缘 |
| 目的地 | 目的地在右边 / 下方 / 左边 / 上方、已经到达目的地、还在起点、与目的地同一行 / 同一列 |
| 手中物品 | 手里有东西、手里空空、有萝卜、有热汤 |
| 小镇物资 | 仓库有萝卜、取餐台有热汤；兼容旧程序 |
| 怪物与伙伴 | 四方向相邻格有怪物、还有怪物没清理、伙伴正在等待 |

例如“如果右边能走，就向右，否则向下”能绕开路障；“如果目的地在左边，就向左”可随人物移动重新判断。重复、判断与组合按关卡的练习内容开放，自由创造全部可用。

## 存档和声音

每次编辑和单步后保存；连续运行时每 3 秒保存；退到后台时暂停并保存。程序、位置、手持物品、自动工作等待状态、嵌套执行进度、库存和关卡都会恢复。关闭应用期间不会自动增加成果。

旧存档会自动迁移：补充闪闪及新地图字段，保留库存、工作统计和原有角色程序。v1.0.0～v1.3.0 的旧七关进度仍映射到对应关卡；更早版本的手动工作指令会移除，已知示例适配纵向地图。旧版第 17、18 关已重新设计，只重置这两关的完成标记；其他星星保留。当前处于这两关时重新准备接力场景，保留物品、库存和程序。

家长设置提供存档导入、导出及清空。Android 导出使用系统文件选择器，不申请全盘存储权限。卸载或清除应用数据会删除存档，建议先导出备份。

应用包含 33 段引导和 20 段动作与结果短句，共 53 段，全部由本机 Qwen3-TTS 按同一快乐儿童声线合成。普通动作约 0.9～2 秒，完成约 2.3 秒、失败约 3 秒，完全离线。新增清怪、交付萝卜及编程练习提示。

当前选中的小动物会播报自己的每个步骤，例如“开始，回到起点”“我来拔萝卜”“向右走一步”“放进仓库啦”。语音依次播放，自动采集在移动前播报，到站工作在移动后播报，画面会配合相应动作。角色的下一条指令等到本次语音播完、到达下个执行周期后再执行；同一行动可以占用多个周期，其他角色照常执行。1× / 2× 调整移动节拍，语音保持原速。

切换所选动物、暂停、静音或修改程序会取消不再适用的语音。缺少食材或前方不通时不会反复播同一句提醒。音频加载失败会释放等待，避免卡住游戏。声音可关闭，静音不影响游戏。

## 开发

技术栈：TypeScript 5.7、Phaser 3.90、Vite 5.4、Capacitor 6.2。

```powershell
npm ci
npm run dev
npm test
npm run build
.\构建Android.ps1
```

Android 构建需要 PowerShell 7、JDK 17 和 Android SDK 35 / Build Tools 35.0.0。设置 `JAVA_HOME`、`ANDROID_SDK_ROOT`，或复用本机 `tools/java17/` 和共享 SDK。Gradle 缓存在 `tools/gradle-cache/`。项目签名保存在 `signing/`，请单独备份并勿公开，后续覆盖安装必须沿用同一签名。源码包不包含签名私钥、模型、SDK、JDK 和依赖缓存。

- `src/model.ts`：职业自动工作、各角色独立执行栈、整轮回家、资源系统和 v1→v2 存档迁移。
- `src/levels.ts`：30 个关卡的起点、人物、地图、移动路障、怪物、编程预算与示例程序。
- `src/scene.ts`：纵向地图、放大的角色、工作台及动画。
- `src/main.ts`：任务、程序轨道、复杂指令编辑器和设置。
- `src/audio.ts`、`src/narration.ts`：动作配音队列、事件顺序、画面呈现与按角色等待。
- `src/drag.ts`：触摸、鼠标和笔的长按排序、自动滚动及拖动后防误删。
- `src/style.css`、`src/workspace.css`：单列竖向布局、紧凑编程工作区、常规 APP 字号和触摸控件。
- `src/program-editor.ts`：重复框路径、排序与删除后的选择位置、内部动作高亮。
- `src/map.ts`：整格地形与阻挡、工作点坐标；场景渲染、移动和道路条件共用。
- `tests/model.test.ts`、`tests/campaign.test.ts`、`tests/program-editor.test.ts`、`tests/learning.test.ts`：97 项逻辑测试，包括全部关卡解法、条件、旧存档、地图地形、重复嵌套、长路最短步数、64 种路障种子、接力依赖、自动清怪及 10,000 拍物品守恒检查。
- `tests/learning-smoke.mjs`：全宽地图、取消缩放、指令预算、嵌套重复、移动路障、萝卜接力和卫士关卡。
- `tests/guard-narration-smoke.mjs`：真实清怪配音、移动后再攻击、怪物按动作提示消失、音频失败时伙伴可继续。
- `tests/map-smoke.mjs`：建筑占格及画面边界、工作点、可走底色、实际碰撞与条件绕路一致性。
- `tests/repeat-block-smoke.mjs`：队列内重复框、原尺寸指令、整框与内部排序、嵌套复杂编辑、关卡清队列及编辑自动暂停。
- `tests/campaign-smoke.mjs`：单人首页、主菜单位置、人物标签、关卡清队列、条件分支与完整程序通关检查。
- `tests/guide-menu-smoke.mjs`：关卡列表当前项高亮、两个说明重播入口、重播从头开始及多尺寸布局。
- `tests/result-narration-smoke.mjs`：真实失败 / 完成音频播完再重置，步模式锁定与星星判定。
- `tests/workspace-smoke.mjs`：场景手势滚动、程序双向滑动、运行中修改、单步执行及高亮跟随。
- `tests/narration-smoke.mjs`：真实音频播放、完整顺序、单步等待、角色并行及音频失败恢复。
- `tests/editor-history-smoke.mjs`：复杂指令删除、清除、撤销，共享动作恢复与开始阶段。
- `tests/browser-smoke.mjs`：删除模式、鼠标/触摸长按排序、复杂编辑器、持续送餐及恢复测试。

当前内容为普通小镇与专用迷宫地图、四个职业伙伴、30 个关卡及自由创造。尚未连接 Android 真机进行设备验收，浏览器与签名构建结果不替代真机测试。
